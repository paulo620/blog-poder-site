Pill-free rounded button (14px radius): lime-green gradient CTA for the main action, frosted-glass ghost for secondary.

```jsx
<Button variant="ghost" href="/blog/">Ler o Blog</Button>
<Button href="https://ibe.ia.br">Conheça a ibe.IA →</Button>
<Button size="sm">Inscreva-se</Button>
```

- `variant`: primary (green gradient, #0a0a0a ink, green glow) | ghost (g-2 glass, border brightens on hover)
- `size`: md 14px 24px / .95rem · sm 10px 18px / .85rem
- Hover lifts -2px (md) / -1px (sm). Arrow "→" is typed in the label.
